# Avisos de terceros

PylandTweaks utiliza o incluye las siguientes herramientas y recursos de
terceros. Los derechos pertenecen a sus respectivos autores.

## Chris Titus Tech - WinUtil

- Uso: inspiración y base de varias optimizaciones.
- Licencia: MIT.
- Proyecto: <https://github.com/ChrisTitusTech/winutil>

## Mem Reduct

- Autor: Henry++.
- Uso: limpieza de memoria RAM (`Recursos/Mem Reduct RAM`).
- Licencia: GPLv3.
- Proyecto: <https://github.com/henrypp/memreduct>
- El binario se distribuye sin modificaciones. El código fuente está disponible
  en el enlace anterior.

## InSpectre

- Autor: Steve Gibson (GRC).
- Uso: consulta y ajuste de mitigaciones de CPU (`Recursos/Mitigaciones CPU`).
- Sitio: <https://www.grc.com/inspectre.htm>

## Quick CPU
